MPC Plus 是面向小程序 CI 的命令行工具。它从当前目录读取配置，解析需要执行的平台和环境，再调用对应平台的上传能力。本地和流水线使用同一条命令。

## 五分钟上手

<Steps>
<Step>

### 安装 CLI

把 CLI 装进项目，锁定团队和 CI 使用的版本：

```npm
npm i -D @mpc-plus/cli
```

</Step>
<Step>

### 创建配置

在项目根目录创建 `mpc.config.ts`：

```ts title="mpc.config.ts"
import { defineConfig } from "@mpc-plus/cli";

export default defineConfig({
  project: {
    root: "./dist/build/mp-weixin",
  },
  release: {
    version: "1.0.0",
    description: "Release v1.0.0",
  },
  platforms: {
    wechat: [
      {
        env: "dev",
        appid: process.env.WX_APPID ?? "",
        privateKeyPath: process.env.WECHAT_PRIVATE_KEY_PATH ?? "./private.key",
      },
    ],
  },
});
```

</Step>
<Step>

### 执行上传

```npm
npm exec -- mpc upload
```

不指定参数时，CLI 会执行配置文件中的全部平台和环境。

</Step>
</Steps>

## 工作流程

1. 在当前工作目录发现 `mpc.config.ts`、`.js`、`.mjs` 或 `.cjs`。
2. 加载配置并解析命令参数。
3. 按平台与环境生成上传目标。
4. 合并全局配置和环境配置。
5. 依次上传，并实时打印每个环节的结果。
