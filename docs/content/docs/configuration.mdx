CLI 会在当前工作目录查找以下文件之一：

```text
mpc.config.ts
mpc.config.js
mpc.config.mjs
mpc.config.cjs
```

推荐使用 TypeScript：

```ts title="mpc.config.ts"
import { defineConfig } from "@mpc-plus/cli";

export default defineConfig({
  project: {
    root: "./dist",
  },
  release: {
    version: "1.0.0",
    description: "Release v1.0.0",
  },
  platforms: {
    wechat: WechatConfig[],
    douyin: DouyinConfig[],
    alipay: AlipayConfig[],
    xhs: XhsConfig[],
  },
});
```

`platforms` 的每个键对应一个平台，值为该平台的环境数组。具体字段见各平台文档：

| 键        | 类型                                         |
| --------- | -------------------------------------------- |
| `wechat`  | [`WechatConfig[]`](/docs/wechat)             |
| `douyin`  | [`DouyinConfig[]`](/docs/douyin)             |
| `alipay`  | [`AlipayConfig[]`](/docs/alipay)             |
| `xhs`     | [`XhsConfig[]`](/docs/xhs)                   |

## 全局配置

| 字段                  | 类型     | 说明                                                         |
| --------------------- | -------- | ------------------------------------------------------------ |
| `project.root`        | `string` | 小程序构建产物目录，上传时必填。                             |
| `release.version`     | `string` | 上传版本号，微信和小红书必填，抖音和支付宝可省略并自动递增。 |
| `release.description` | `string` | 版本说明，微信和支付宝可选，抖音和小红书必填。               |
| `platforms`           | `object` | 平台配置集合，键为平台名，值为该平台的环境数组。             |
