抖音上传基于 `tt-ide-cli`。执行前需要准备：

- 已完成构建的抖音小程序目录。
- 小程序 `appid`。
- 对应小程序的上传 Token。

## 配置示例

```ts title="mpc.config.ts"
import { defineConfig } from "@mpc-plus/cli";

export default defineConfig({
  project: {
    root: "./dist/build/mp-toutiao",
  },
  release: {
    version: "1.0.0",
    description: "优化首页体验",
  },
  platforms: {
    douyin: [
      {
        env: "test",
        appid: process.env.DOUYIN_APPID ?? "",
        token: process.env.DOUYIN_TOKEN ?? "",
      },
      {
        env: "prod",
        appid: process.env.DOUYIN_APPID ?? "",
        token: process.env.DOUYIN_TOKEN ?? "",
      },
    ],
  },
});
```

`--env` 会作为 Vite mode 加载对应环境文件。创建 `.env.test` 和 `.env.prod`：

```dotenv title=".env.test"
DOUYIN_APPID=tt-test-appid
DOUYIN_TOKEN=your-test-upload-token
```

```dotenv title=".env.prod"
DOUYIN_APPID=tt-prod-appid
DOUYIN_TOKEN=your-prod-upload-token
```

```npm
npm exec -- mpc upload --platform douyin --env test
```

Token 不要提交到仓库。

## 配置项

| 字段                         | 说明                                                         |
| ---------------------------- | ------------------------------------------------------------ |
| `env`                        | `string`。环境标识，CLI `--env` 按此筛选。必填。             |
| `appid`                      | `string`。小程序 AppID。必填，且必须与 `project.config.json` 中的 `appid` 一致。 |
| `token`                      | `string`。上传 Token。必填。官方工具会写入本机 CLI 配置，不要提交到仓库。 |
| `project`                    | `ProjectConfig`。覆盖全局 `project`，未设置的字段继承全局值。 |
| `project.root`               | `string`。已构建的抖音小程序目录。必填。                     |
| `release`                    | `ReleaseConfig`。覆盖全局 `release`，未设置的字段继承全局值。 |
| `release.version`            | `string`。上传版本号。可选；填写时须为 `x.y.z`，省略则由官方工具自动递增。 |
| `release.description`        | `string`。版本说明，对应官方工具的 `changeLog`。必填。       |
| `upload`                     | `DouyinUploadOptions`。透传 `tt-ide-cli` 上传参数。可选。    |
| `upload.channel`             | `string`。抖音测试通道，与 MPC 的 `env` 环境标识相互独立。   |
| `upload.needUploadSourcemap` | `boolean`。是否上传 source map。                             |
