小红书上传基于官方 `xhs-mp-cli`。执行前需要准备：

- 在小红书小程序控制台的「基础设置 → 代码上传秘钥」生成上传 Token。
- 已完成构建、且包含 `project.config.json` 的小程序目录。

## 配置示例

```ts title="mpc.config.ts"
import { defineConfig } from "@mpc-plus/cli";

export default defineConfig({
  project: {
    root: "./dist/build/mp-xhs",
  },
  release: {
    version: "1.0.0",
    description: "优化首页体验",
  },
  platforms: {
    xhs: [
      {
        env: "test",
        appid: process.env.XHS_APPID ?? "",
        token: process.env.XHS_TOKEN ?? "",
      },
      {
        env: "prod",
        appid: process.env.XHS_APPID ?? "",
        token: process.env.XHS_TOKEN ?? "",
      },
    ],
  },
});
```

`--env` 会作为 Vite mode 加载对应环境文件。创建 `.env.test` 和 `.env.prod`：

```dotenv title=".env.test"
XHS_APPID=your-test-app-id
XHS_TOKEN=your-test-upload-token
```

```dotenv title=".env.prod"
XHS_APPID=your-prod-app-id
XHS_TOKEN=your-prod-upload-token
```

```npm
npm exec -- mpc upload --platform xhs --env test
```

Token 不要提交到仓库。

## 配置项

| 字段                  | 说明                                                         |
| --------------------- | ------------------------------------------------------------ |
| `env`                 | `string`。环境标识，CLI `--env` 按此筛选。必填。             |
| `appid`               | `string`。小程序 AppID。必填，且必须与 `project.config.json` 中的 `appid` 一致。 |
| `token`               | `string`。代码上传 Token。必填。仅支持 Token 认证，失败不会扫码登录。官方工具会写入本机配置，不要提交到仓库。 |
| `project`             | `ProjectConfig`。覆盖全局 `project`，未设置的字段继承全局值。 |
| `project.root`        | `string`。包含 `project.config.json` 的构建产物目录。必填。  |
| `release`             | `ReleaseConfig`。覆盖全局 `release`，未设置的字段继承全局值。 |
| `release.version`     | `string`。上传版本号。必填；原样传递，不限制为 `x.y.z`，也不自动递增。 |
| `release.description` | `string`。版本说明，对应官方上传参数 `desc`。必填。          |

官方文档：[命令行工具](https://miniapp.xiaohongshu.com/doc/DC459669)、[秘钥免密登录](https://miniapp.xiaohongshu.com/doc/DC630678)。
