支付宝上传基于官方 `minidev`。执行前需要准备：

- 支付宝小程序 AppID。
- 从支付宝开放平台下载的身份密钥文件。
- 已完成构建的支付宝小程序目录。

## 配置示例

```ts title="mpc.config.ts"
import { defineConfig } from "@mpc-plus/cli";

export default defineConfig({
  project: {
    root: "./dist/build/mp-alipay",
  },
  release: {
    version: "1.0.0",
    description: "优化首页体验",
  },
  platforms: {
    alipay: [
      {
        env: "test",
        appid: process.env.ALIPAY_APPID ?? "",
        identityKeyPath: process.env.ALIPAY_IDENTITY_KEY_PATH ?? "",
      },
      {
        env: "prod",
        appid: process.env.ALIPAY_APPID ?? "",
        identityKeyPath: process.env.ALIPAY_IDENTITY_KEY_PATH ?? "",
      },
    ],
  },
});
```

`--env` 会作为 Vite mode 加载对应环境文件。创建 `.env.test` 和 `.env.prod`：

```dotenv title=".env.test"
ALIPAY_APPID=2026000000000001
ALIPAY_IDENTITY_KEY_PATH=/absolute/path/to/identity.test.json
```

```dotenv title=".env.prod"
ALIPAY_APPID=2026000000000000
ALIPAY_IDENTITY_KEY_PATH=/absolute/path/to/identity.prod.json
```

```npm
npm exec -- mpc upload --platform alipay --env test
```

路径相对于执行命令的工作目录解析，也可以使用绝对路径。身份密钥文件不要提交到仓库。

## 配置项

| 字段                  | 说明                                                         |
| --------------------- | ------------------------------------------------------------ |
| `env`                 | `string`。环境标识，CLI `--env` 按此筛选。必填。             |
| `appid`               | `string`。小程序 AppID。必填。                               |
| `identityKeyPath`     | `string`。身份密钥文件路径。必填，不会回退到本机快速授权。   |
| `project`             | `ProjectConfig`。覆盖全局 `project`，未设置的字段继承全局值。 |
| `project.root`        | `string`。已构建的支付宝小程序目录。必填。                   |
| `release`             | `ReleaseConfig`。覆盖全局 `release`，未设置的字段继承全局值。 |
| `release.version`     | `string`。上传版本号。可选；填写时须为三段数字 `x.y.z`，省略则由支付宝自动递增。全局版本会被环境继承；若希望支付宝单独自动递增，设置 `release: { version: undefined }`。 |
| `release.description` | `string`。版本说明，对应 SDK 的 `versionDescription`。可选。 |
| `upload`              | `AlipayUploadOptions`。透传 `minidev` 上传参数。可选。       |
| `upload.experience`   | `boolean`。上传后是否设为体验版，默认 `false`。需要相应平台权限。 |

官方说明：[upload 上传项目](https://opendocs.alipay.com/mini/02q3an?pathHash=12060a6b)。
